# Security policy

Version 1.x is the current supported line. This project evaluates only its named
CVEs and does not guarantee absence of other PHP vulnerabilities.

For a vulnerability in this tool, use GitHub's private vulnerability-reporting
option if enabled by the repository owner. If it is unavailable, open an issue
requesting a private contact channel without posting sensitive details or working
exploit payloads. Do not post credentials, customer URLs, or production reports.

Include the tool/Python version, sanitized steps, affected component and impact.
False classification reports should specify whether the result concerned an
archive or HTTP endpoint and supply non-sensitive evidence provenance.

Repository maintainers should enable private vulnerability reporting before a
public release. No response-time commitment is implied.
